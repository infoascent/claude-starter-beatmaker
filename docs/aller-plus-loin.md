# Aller plus loin (à lire quand tu en as besoin, pas avant)

## Les mots, en une ligne chacun

- **Claude Code** : Claude qui agit sur ton ordi (fichiers, outils, navigateur), pas juste qui répond.
- **CLAUDE.md** : le fichier mémoire relu à chaque conversation. Ton « cerveau ».
- **Skill** : un preset de savoir-faire. Dossier dans `~/.claude/skills/`. Claude peut en créer pour toi.
- **API** : la prise électrique d'un service (Gmail, Spotify, YouTube...).
- **Clé API** : le code d'accès à cette prise. Se range dans `~/Claude/memoire/secrets.env`, jamais dans le chat.
- **MCP / connecteur** : la multiprise toute prête qui branche Claude à un service.
- **GitHub** : un coffre-fort en ligne pour tes projets, avec toutes les versions. Gratuit.
- **Vercel** : l'hébergeur gratuit qui met un site en ligne à partir de GitHub.
- **Terminal** : la fenêtre où Claude tape ses commandes. Tu n'as jamais besoin d'y toucher.

## Les connecteurs utiles pour un beatmaker

À activer dans l'app Claude : Paramètres > Connecteurs. 2 clics, aucune technique.

| Connecteur | Ce que ça permet |
|---|---|
| Gmail | Retrouver un échange avec un artiste, préparer des réponses (envoi seulement si tu valides) |
| Google Drive | Lire et ranger tes dossiers de prods partagés, préparer des packs |
| Google Calendar | Caler tes sessions studio, tes deadlines de projets |
| Notion | Si tu tiens tes projets ou tes contacts dedans |

Plus tard, selon tes projets (Claude s'occupe de l'installation, tu crées juste les comptes) :

- **YouTube Data API** : suivre les stats de tes type beats, préparer les mises en ligne.
- **Spotify API** : analyser les playlists et les artistes de ta niche.
- **Kie.ai, Higgsfield ou équivalent** : générer des visuels de covers et de miniatures (payant à l'usage, petits montants, toujours avec ton accord).

## Les commandes à connaître dans Claude Code

- `/` : affiche la liste des commandes et de tes skills.
- `/clear` : vide la conversation pour repartir sur un nouveau sujet (ta mémoire reste).
- `/apprendre` : reprendre le cours.
- Tu peux glisser une capture d'écran ou un fichier directement dans la conversation.

## Limites à connaître

- **Ton abonnement a un quota.** Les grosses tâches (site complet, analyse de 500 sons)
  consomment plus. Si tu atteins la limite, ça se débloque après quelques heures.
- **Claude peut se tromper.** Vérifie toujours ce qui compte vraiment (un message avant envoi,
  une info de contrat, un BPM à l'oreille).
- **Sauvegarde tes sons ailleurs** (disque externe ou cloud). Claude a pour règle de ne jamais
  toucher à tes originaux, mais une sauvegarde reste la base de tout producteur.

## Idées de projets pour la suite

- Un site avec ta page de vente de drumkit ou de beats.
- Un tableau de suivi de tes collabs et placements (qui, quoi, statut, splits).
- Un modèle de split sheet (répartition des droits entre co-auteurs) à faire valider par un
  pro ou ta société de gestion de droits avant signature.
- Des idées de contenu Instagram / TikTok à partir de tes sessions.
- Un planning de sorties pour ta chaîne YouTube type beat.
- Un skill qui prépare automatiquement tout ce que tu fais à chaque nouvelle prod.
