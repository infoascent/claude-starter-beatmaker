# Claude Starter Beatmaker

Le kit pour démarrer Claude Code de zéro, sans rien connaître au code.
En 20 minutes, ton Claude Code est configuré, il te connaît, et tu sais t'en servir.

---

## Ce que tu as à faire (2 étapes, c'est tout)

**1. Ouvre l'application Claude, onglet « Code ».**
Quand elle te demande un dossier, crée un dossier `Claude` dans ton dossier perso (ou tes Documents) et choisis-le.

**2. Copie-colle ce message à Claude, tel quel :**

```
Installe-moi le setup de ce lien en suivant son fichier INSTALL.md à la lettre :
https://github.com/infoascent/claude-starter-beatmaker
```

C'est Claude qui fait tout le reste. Il va :

- te demander d'autoriser quelques actions au début (clique sur « Autoriser », c'est normal, c'est la dernière fois)
- configurer ton Claude Code pour qu'il arrête de te demander la permission à chaque action
- te poser 9 questions rapides pour te connaître (ton son, tes objectifs, ta façon de bosser)
- installer tes premiers « skills » (des savoir-faire prêts à l'emploi : site web, catalogue de sons, pitch aux artistes, titres type beat YouTube)
- te faire un mini-cours en 7 leçons de 5 minutes, avec un vrai résultat à chaque fois

À la fin tu tapes `/apprendre` quand tu veux reprendre le cours là où tu l'as laissé.

---

## Ce qu'il y a dans ce dossier (pour les curieux)

| Fichier | À quoi ça sert |
|---|---|
| `INSTALL.md` | Le mode d'emploi que Claude suit pour t'installer (pas pour toi) |
| `config/settings.json` | Les réglages : plus de « Autoriser ? » à chaque action, avec des garde-fous |
| `config/CLAUDE.md` | Le « cerveau » de ton Claude : qui tu es, comment il doit bosser avec toi |
| `skills/` | Tes savoir-faire de départ, utilisables en tapant `/` dans Claude Code |
| `docs/aller-plus-loin.md` | MCP, API, connecteurs, GitHub : expliqués simplement, pour plus tard |
