# Claude Starter

Le setup de base pour démarrer Claude Code, rien de plus.

## Ce que tu as à faire

**1.** Ouvre l'application Claude, onglet « Code ». Quand elle te demande un dossier,
crée un dossier `Claude` dans ton dossier perso et choisis-le.

**2.** Copie-colle ce message à Claude :

```
Installe-moi le setup de ce lien en suivant son fichier INSTALL.md à la lettre :
https://github.com/infoascent/claude-starter-beatmaker
```

Clique sur « Autoriser » les premières fois. Après l'installation, Claude ne te demandera plus
la permission.

## Ce que ça installe

- Claude agit sans te demander l'autorisation à chaque action.
- Un dossier `~/Claude/brain/` : la mémoire de ton Claude (qui tu es, tes décisions, ton
  journal, tes clés). Il le relit à chaque conversation.

Pour tout le reste : demande à Claude. Il est là pour ça.
